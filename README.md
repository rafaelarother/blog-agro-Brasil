# 🌱 AgroBrasil

> Blog brasileiro sobre agricultura, pecuária, tecnologia e agronegócio.

O **AgroBrasil** é um projeto de blog desenvolvido para compartilhar conteúdos relacionados ao campo brasileiro.

## 🚜 Sobre o projeto

O site aborda temas como:

- 🌱 Agricultura
- 🐂 Pecuária
- 🚜 Tecnologia no campo
- 🌾 Sustentabilidade
- 🇧🇷 Agronegócio brasileiro
- 🛰️ Agricultura de precisão
- 🐄 Produção animal
- 📈 Tendências do setor

## 🎨 Design

O projeto utiliza uma identidade visual inspirada no campo brasileiro.

### Principais cores

- Verde escuro: `#123b22`
- Verde: `#1f6b3a`
- Verde claro: `#3d8b51`
- Amarelo: `#dcae32`
- Marrom: `#744a29`
- Branco: `#ffffff`
